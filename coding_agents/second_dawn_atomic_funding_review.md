# Atomic resource conversion for research and build

Outcome: a player can confirm a resource conversion and its purchase together, with no money spent if the research/build action is invalid.

Added the strictly typed trade-and-act wrapper, restricted to research/build, plus Convex structural validation. Each command allows one or two distinct source currencies converting directly into science for research or materials for build. Conversions must cover exactly the shortfall at the faction's actual exchange ratio. No chaining, fractional amounts, duplicate source currencies or unnecessary surplus conversions. Ownership, active turn, pending decision and action phase are checked; the ordinary action then applies all original legality, supply, technology, activation/reaction and influence rules. Pure cloned-state processing commits conversions and action together or returns an error with input unchanged. The adapter writes one revision/journal entry; duplicate command submission returns the prior receipt without spending again.

fundingOptions(view, action) produces at most16 source allocations including both extremes, each using at most2 source resources. It returns price, shortfall, balances after conversion and after purchase, and the exact typed wrapper command. It is a funding estimate; it does not replace ordinary action legality. commandPreview projects the converted public resources then the ordinary action, retaining upkeep/influence calculations. Public history names the purchase and conversion amounts. AI candidate generation remains unchanged; AI still uses normal trade/action commands under the same rules.

Tests failed first for missing funding API, then passed. Six new pure/Convex scenarios cover mixed source conversion, exact price, preview parity, invalid action rollback, wrong actor/pending decision, already affordable and impossible funding, a real built ship, 3:1 alien exchange, malformed/chained/duplicate conversions, and idempotent persisted research with one public history entry. Existing action and public-history suites pass with them:17 tests in the focused batch. Scoped lint passes; production build passes. Full repository lint debt remains separate.

No catalog/rules version bump or persistence migration: this is an atomic command composition of existing base-game trades plus existing actions, not a new rule. Rollback can remove the wrapper UI while retaining original standalone commands and historic journal entries.
